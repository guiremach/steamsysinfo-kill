# Steamsysinfo.exe killer

Start Steam and stop steamsysinfo.exe that consume a lot CPU and crash games.

## Features

- For a faster start, prevent gldriverquery on startup, Launching and closing Steam twice.

** (Disable if you want - remove lines 12 through 23) 

## Installation
- Install and run steam at least one time.
- Download the script.
- Edit the path the script if the Steam path is not the default one at - `C:\Program Files (x86)`.
- Execute `startsteam.bat`

**Supported platforms:**
- Windows (10/11 - Server 2019/2022/2025)

## Uninstallation

Delete the file.
